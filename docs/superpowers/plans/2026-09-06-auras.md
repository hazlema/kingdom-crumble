# Auras Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A curated `aura` sidecar key — pieces name an ambient particle effect (green smog on Halloween crates, the owner's ask) and the spawners attach it; cosmetic only, sidecar-first doctrine intact.

**Architecture:** One task. A new `Auras` static registry (`src/level/auras.gd`) holds the baked table (id → capped particle config) and a generic `attach()`; `Pieces.parse_sidecar` learns the `aura` key (curated, warn-and-drop unknown, exactly like `powerup`); the two production spawn paths (crates via LevelBuilder, props via PropBuilder) call `Auras.attach`. Docs fold in.

**Tech Stack:** Godot 4.6.3, GDScript, GUT headless.

## Global Constraints

- Godot binary: `/home/frosty/Dev/godot/bin/godot`
- Full suite (baseline **372 passing**): `godot --headless -s addons/gut/gut_cmdln.gd -gdir=res://tests -ginclude_subdirs -gexit`. GUT counts engine errors as failures; deliberate warn-path tests only.
- **DEPLOY FREEZE: commit locally only. NO push/export/deploy.**
- **Sidecar-first doctrine:** the aura DEFINITIONS (colors, particle counts, speeds) are BAKED in the `Auras.KNOWN` table — a sidecar can only pick a name. This is the security stance (a hostile pack can say "smog-green", never "amount: 500000") and the performance cap in one move.
- Inert-data doctrine: unknown aura NAME → `push_warning` + skip, never crash. Wrong TYPE in a sidecar follows `parse_sidecar`'s existing patterns.
- Auras are COSMETIC ONLY: a `CPUParticles2D` child, no physics interaction, no scoring/trigger visibility. Caps baked into the table: `amount` ≤ 12, particle alpha ≤ 0.6, modest lifetimes.
- `local_coords = false` on the emitter so smoke trails linger in world space when a crate tumbles.
- Particles draw behind the piece art (`z_index` below the sprite) so the piece face stays readable.
- V1 curated set (exactly these ids): `smog-green`, `mist`, `sparkle`, `embers`. Colors/dials are implementer-tuned within the caps; `smog-green` reads as translucent sickly green rising slowly.
- Headless tests share the real `user://` — any test pack fixtures must use the existing `test_toybox.gd` helpers' patterns (sandboxed `Pieces.toybox_root`, full cleanup) or avoid user:// entirely.
- Editor TEST runs the real spawners, so auras appear there for free; the editor's edit-mode canvas draws textures, not spawned bodies — no editor work in scope.

**Interfaces:**
